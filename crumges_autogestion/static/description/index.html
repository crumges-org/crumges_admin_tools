Crumges Autogestión

Acceso a Autogestión desde Odoo para que cada cliente gestione su propio servidor: ícono en la barra superior con el estado (recursos, instancias, respaldos y avisos) y opción «Autogestión» en el menú del usuario. Lo ven los usuarios con el permiso Autogestión / Usuario. Además quita del menú del usuario Soporte, Mi cuenta de Odoo.com e Instalar aplicación.
